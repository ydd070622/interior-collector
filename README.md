# Interior Collector · 室内灵感采集

Chrome 室内设计图集采集扩展，当前版本 **1.0.1**。

## 下载与安装

推荐下载本仓库 Releases 中的 **interior-collector-v1.0.1.zip**。安装包包含全部代码、模型和运行库，无需安装 Node、Python 或 Git。

1. 解压 ZIP，保留整个 interior-collector 文件夹。
2. Chrome 打开 chrome://extensions，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的 interior-collector 文件夹。
4. 将插件固定到工具栏；在网站点击插件打开独立小窗。

安装后不要删除或移动插件文件夹。Chrome 116 或更高版本。

**请使用 Release 中的完整安装包。** 本仓库的 ONNX 模型使用 Git LFS 存储，GitHub 的 Code → Download ZIP 源码包可能包含模型指针，不能保证解压即可运行。

开发者克隆时安装 Git LFS，再运行 git lfs pull 获取模型。

## 使用

### 1.0.1 更新（2026-10-15）

- 新增案例下载历史和跨文件夹去重，按来源与图片指纹识别重复，显示原保存位置。
- 支持图片对比、跳过、单独保存与补充合并，合并前检查原案例文件和写入授权。
- 索引统一存入插件内部数据库，自动迁移旧 JSON；现有图片扫描去重继续保留。
- 放大重复提醒，精简说明；每组图片左右对比，每排组数随窗口宽度自动增加，保持竖向滚动。
- 清理旧备用工作副本、临时文件和桌面版源码；桌面版由独立源码维护。

### 采集与下载

- 列表页先填写图文篇数，再点击“开始提取”；留空表示不限定篇数。
- 已适配的小红书、站酷、室内设计联盟单篇详情会自动读取图集。
- 支持滚动加载和可识别的下一页按钮；视频和重复案例不占图文篇数。
- 提取类型默认“室内”；选择“其他”后重新扫描，不限题材，继续保留尺寸过滤与去重。
- 图片按 01-案例标题/001.png 分文件夹保存，编号接续保存目录已有文件夹；特殊标题自动兼容。
- 点击缩略图可打开独立原图预览，点击原图切换实际尺寸，Esc 关闭。
- 图片右上角 × 可屏蔽下载，点击“恢复”重新加入；重新扫描重置屏蔽。
- 采集窗口支持调整大小，图片列数自动适配；重新扫描读取最近使用的浏览器窗口当前网页。
- PNG 保留透明；JPG 使用白色背景，质量固定 100%。
- 点击“保存文件夹”选择普通文件夹，允许 Chrome 写入；否则保存到 Chrome 默认下载目录的“室内灵感”子目录。
- 下载前自动检查案例历史：同一原文或图片重合时，显示已有案例、首次下载日期和图片对比，可选择“合并到原案例”“单独保存”“跳过本案例”。标题相同不会自动合并。
- 合并仅追加未重合图片，保留两次采集的来源；不删除已有图片。现有扫描图片去重继续保留。
- 选择保存文件夹后，为该目录直接下一级案例文件夹的旧图片建立本地索引（首次较慢），不会扫描电脑其他目录。所有已建立的索引统一参与比对，不受日期、风格或项目文件夹划分影响；匹配提醒显示原保存位置。单独保存写入当前目录，合并写入原目录；合并时请求原目录写入授权，并重新检查该案例的文件。原目录移动、删除或拒绝授权时，可选择单独保存。其他历史文件夹不会每次全盘扫描。
- 索引集中保存在插件内部 IndexedDB 数据库 `interior-collector` 的 `settings` 存储区；素材目录不再生成 JSON 文件。下次下载会自动迁移并移除旧版 `.interior-case-history.json`，保留来源和时间。清除插件数据或卸载插件会清除内部历史，之后可从图片重建指纹。默认下载模式只能追踪新功能启用后成功下载的文件。
- 查看内部索引：在 Chrome 扩展管理页打开本插件的 Service Worker 检查窗口，进入 Application → IndexedDB → interior-collector → settings。Windows 下物理数据由 Chrome 管理，通常位于当前配置目录的 `IndexedDB/chrome-extension_<扩展ID>_0.indexeddb.leveldb/`，不是可直接编辑的 JSON；配置目录可在 `chrome://version` 的“个人资料路径”查看。更换保存目录不会清除旧目录的索引。
- 图片比对支持轻微压缩和等比例缩放，采用保守阈值；明显裁剪、加水印、角度变化可能无法识别。多图案例至少有两张图片相似才提示跨来源合并，由用户决定是否合并。旧案例导入前的下载日期未知，不会编造日期。
- 小窗可拖动，点击其他区域不会自动关闭。后台任务继续运行；退出 Chrome 或重新加载扩展会停止任务。

## 识别与图片范围

图片在本机通过量化 CLIP 模型识别，不上传 AI 服务。首次加载模型可能耗时。

按实际解码尺寸过滤：短边至少 600px，或长边至少 1000px 且短边至少 400px；宽高比例不超过 4。1280×557 可以通过尺寸过滤，200 多像素的缩略图不会被放大充当原图。最终仍须通过室内分类。

专用适配读取案例正文，排除广告、推荐、头像、评论和列表缩略图。室内设计联盟只读案例首帖附件原图。其他网站使用通用案例结构识别，无法确定正文时提示待适配。

登录、验证码、网站结构改变和图片访问限制可能造成读取失败。具体验证记录见 TEST-REPORT.md。

## 运行资源

随安装包提供 Transformers.js、ONNX Runtime WASM、Xenova/clip-vit-base-patch32 量化模型。第三方许可证保留在 vendor/ 和 models/ 中。
